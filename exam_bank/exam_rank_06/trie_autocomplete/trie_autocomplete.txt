Assignment name  : trie_autocomplete
Expected files   : trie_autocomplete.py
--------------------------------------------------------------------------------

Write a function that implements an autocomplete system using a Trie (prefix tree) data structure.
The function should insert a list of words into the Trie and find all words that start with a given prefix.

The function should:
- Build a Trie from the list of words.
- Return all unique words that start with the given prefix.
- Return results in alphabetical (lexicographical) order.
- Handle an empty prefix by returning all unique words sorted.
- Return an empty list if no matches are found.
- Be case-sensitive.
- Ensure duplicate words in the input appear only once in the output.

Prototype:

    def trie_autocomplete(words: list[str], prefix: str) -> list[str]:

Examples:

    trie_autocomplete(["apple", "app", "apricot", "banana"], "app")  ->  ["app", "apple"]
    trie_autocomplete(["apple", "app", "apricot", "banana"], "ban")  ->  ["banana"]
    trie_autocomplete(["hello", "world", "help", "heap"], "he")      ->  ["heap", "hello", "help"]
    trie_autocomplete(["test"], "xyz")                               ->  []
    trie_autocomplete(["cat", "car", "card", "care"], "car")         ->  ["car", "card", "care"]
    trie_autocomplete([], "test")                                    ->  []
    trie_autocomplete(["a", "ab", "abc"], "")                        ->  ["a", "ab", "abc"]
