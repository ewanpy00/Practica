Assignment name  : union_find_system
Expected files   : union_find_system.py
--------------------------------------------------------------------------------

Write a class named `UnionFind` that implements a Disjoint Set Union (DSU) data structure with path compression and union by rank optimizations.

The class must provide the following methods:

1. `__init__(self, n: int)`:
Initializes `n` elements (from 0 to n - 1), where each element initially belongs to its own separate set (parent is itself, and rank is 0).

2. `find(self, x: int) -> int`:
Finds and returns the representative (root) of the set containing element `x`. Implements path compression so that every traversed node points directly to the root.

3. `union(self, x: int, y: int) -> bool`:
Merges the set containing `x` with the set containing `y` using union by rank (attaching the tree of smaller rank under the root of larger rank; if ranks are equal, increment the rank of the chosen new root).
Returns `True` if `x` and `y` were in different sets and successfully merged.
Returns `False` if `x` and `y` were already in the same set.

4. `connected(self, x: int, y: int) -> bool`:
Returns `True` if `x` and `y` belong to the same set, and `False` otherwise.

Prototype:

    class UnionFind:
        def __init__(self, n: int):
        def find(self, x: int) -> int:
        def union(self, x: int, y: int) -> bool:
        def connected(self, x: int, y: int) -> bool:

Examples:

    uf = UnionFind(5); uf.connected(0, 1)                                        ->  False
    uf = UnionFind(5); uf.union(0, 1)                                            ->  True
    uf = UnionFind(5); uf.union(0, 1); uf.connected(0, 1)                        ->  True
    uf = UnionFind(5); uf.union(0, 1); uf.union(1, 2); uf.connected(0, 2)        ->  True
    uf = UnionFind(5); uf.union(0, 1); uf.union(0, 1)                            ->  False
    uf = UnionFind(3); uf.union(0, 1); uf.union(1, 2); uf.find(0) == uf.find(2)  ->  True
